**What This Language Is**
L is just a basic language I'm building to get better at cpp while experimenting with features I personally think should be in mainstream languages. Im planning to keep the syntax easy 
and I want to make this language intuitive for any person, wether they are starting programming or experienced.


**Why I'm Making This Project**
This project is only for me to learn the more in depth concepts of cpp and apply them as i create my own basic interpreter. In no way do i plan to ever launch this language or for people 
use it in any productive way except for beginners to learn like me from the code I write.
